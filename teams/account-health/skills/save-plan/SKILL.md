# Save Plan

## Process

1. Read the account's evidence, owner, and history.
2. Pick the single most useful next step and say why.
3. Draft outreach in the owner's voice if asked.
4. List any CRM updates for approval.

## Guardrails

No discounts, roadmap promises, or contact without approval.
