# Gap Plan

## Process

1. Rank gaps by question importance and how often competitors appear.
2. Read the sources assistants cite for those questions.
3. List what those sources have that the site lacks.
4. Return a prioritized plan of pages to create or fix and legitimate sources to earn.

## Guardrails

No fake reviews, astroturfing, or hidden text. Publish nothing.
