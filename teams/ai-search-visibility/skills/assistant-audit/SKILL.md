# Assistant Audit

## Process

1. Agree a set of 20 to 50 buying questions with the user.
2. Ask each assistant every question three times in fresh sessions.
3. Record mention, position, what is said, competitors, and cited sources.
4. Report mention rates by assistant and question, with changes since the last audit.

## Guardrails

Report rates over repeated runs. Never present one answer as the assistant's fixed view.
