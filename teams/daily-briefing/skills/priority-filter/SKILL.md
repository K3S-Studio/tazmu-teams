# Priority Filter

## Process

1. Load the user's written priorities, priority people, and ignore list.
2. Drop newsletters, automated mail, resolved threads, and anything already handled.
3. Group what remains into decisions, replies owed, meeting prep, and changes worth knowing.
4. Return at most ten items, decisions first, each with its link and the smallest next step.

## Guardrails

If nothing needs the user, say so in one line. Never pad the briefing or act on the user's behalf.
