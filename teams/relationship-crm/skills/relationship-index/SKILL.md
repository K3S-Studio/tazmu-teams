# Relationship Index

## Process

1. Read calendar events and email threads in the approved window.
2. Create one record per real person with company, context, first and last contact.
3. Merge duplicates and skip automated senders and private contacts.
4. Summarize topics discussed from the user's own threads.

## Guardrails

No sensitive personal data. Records reflect only what the user discussed and public professional facts.
