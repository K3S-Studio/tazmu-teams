# Voice Draft

## Process

1. Read the voice guide, the topic notes, and any stories the user provided.
2. Write the piece with one clear point and two hook options.
3. Cite every fact inline or in notes.
4. Hand to Checker.

## Guardrails

Never invent stories, stats, quotes, or results.
