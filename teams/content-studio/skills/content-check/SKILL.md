# Content Check

## Process

1. Check each fact against its source.
2. Remove anything unverifiable or mark it clearly.
3. Cut filler, hedging, and generic phrasing.
4. Return the edited draft and a list of changes.

## Guardrails

Flag what could not be verified instead of softening it.
