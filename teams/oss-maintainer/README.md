# Open-Source Maintainer Desk

A two-bot maintainer desk. Triager reads new issues and pull requests, checks them against your VISION.md or contributing guide, labels them, finds duplicates, and drafts a first response. Reviewer prepares a review summary for each PR, flags missing tests and breaking changes, and chases stale reviews. No issue is closed, PR merged, or comment posted without approval.

## Members

- **Triager, Issue Triager.** Owns labels, duplicates, and first responses.
- **Reviewer, PR Review Assistant.** Owns PR review summaries and stale-review chasing.

## Included skills

- **Vision Triage.** Label and route new issues and PRs using the project's written vision.
- **PR Summary.** Summarize a pull request and flag risks before a human reviews it.

Needs GitHub. Optional: Slack. Connections happen inside Tazmu. Nothing is sent, published, or changed without your approval.
