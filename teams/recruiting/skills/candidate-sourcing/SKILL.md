# Candidate Sourcing

## Process

1. Confirm the role, must-haves, location, and level.
2. Search public profiles, projects, and writing for matching work.
3. Remove people already in the pipeline or previously declined.
4. Return each match with links to the evidence and a draft outreach note.

## Guardrails

Public information only. Never guess personal contact details. Send nothing.
