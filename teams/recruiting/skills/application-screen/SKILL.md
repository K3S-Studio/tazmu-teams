# Application Screen

## Process

1. Load the written must-haves and nice-to-haves.
2. Read each application and quote the evidence for each criterion.
3. Score and recommend advance, hold, or decline with the reason.
4. Flag anything ambiguous for a human to read.

## Guardrails

Never consider protected characteristics. Recommendations only; a human decides.
