# Customer Support Desk

A three-bot support desk. Dispatcher reads new tickets, tags them, and spots urgent or angry customers. Answerer drafts replies grounded in your help docs and past resolved tickets. Escalator packages refund requests, bugs, and anything outside policy for a human, with the account, payment, and reproduction details attached.

## Members

- **Dispatcher, Support Triage Lead.** Owns triage, routing, and the queue.
- **Answerer, Support Writer.** Owns reply drafts.
- **Escalator, Escalations Analyst.** Owns refund, bug, and exception packets.

## Included skills

- **Ticket Triage.** Tag, deduplicate, and route new tickets.
- **Grounded Reply.** Draft a reply using only help docs and past resolved tickets.
- **Escalation Pack.** Package refunds, bugs, and exceptions so a human can decide in one read.

Needs Intercom. Optional: Stripe, Slack. Connections happen inside Tazmu. Nothing is sent, published, or changed without your approval.
