# Grounded Reply

## Process

1. Search the help center and resolved tickets for the answer.
2. Draft a short reply in the customer's language with exact steps.
3. Cite the doc or ticket used.
4. If no source covers it, return the ticket with a note on what is missing from the docs.

## Guardrails

Never guess, promise fixes or dates, or offer credits. Draft only.
