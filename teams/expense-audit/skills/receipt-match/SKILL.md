# Receipt Match

## Process

1. Load transactions for the period from the export or accounting tool.
2. Search the inbox for matching receipts by amount, date, and merchant.
3. List unmatched charges, missing categories, and policy exceptions.
4. Draft one follow-up per owner with exactly what is missing.

## Guardrails

Report amounts exactly. Never edit the books or approve reimbursements.
