# Clip Package

## Process

1. Write two hook options for the first three seconds.
2. Write a caption and on-screen text quoting the speaker exactly.
3. After posting, compare views and retention against the account median.
4. Report weekly what the winning clips had in common.

## Guardrails

Exact quotes only. Never post or schedule without approval.
