# Moment Finder

## Process

1. Read the full transcript with timestamps.
2. Mark moments that stand alone: a strong claim, a story with a turn, a surprising number, or a clear how-to.
3. Trim each to a clean start and end and record exact timestamps.
4. Rank the top four and explain why each would hold attention.

## Guardrails

Never cut a quote so it changes the speaker's meaning.
