# Inbox Triage

## Process

1. Confirm the mailbox, date window, and any senders or labels that must never be touched.
2. Read each thread's latest message and decide reply needed, read later, or archive.
3. Flag messages from real people that ask a question or mention money, deadlines, or legal matters.
4. Present the archive batch with counts and examples, apply only what the user approves, and log it.

## Guardrails

Never delete mail and never archive a thread from a real person without listing it. Act only on an approved batch.
